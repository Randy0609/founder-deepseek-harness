# 插件包目录

此目录目前没有插件包。`docs/PLUGIN-ROADMAP.md` 记录候选包；只有进入实际实现时才建立 `packages/<name>/`。

未来的包按[跨行业任务契约](../docs/TASK-ERP.md)分工：公共能力描述任务、证据和来源；企业或行业扩展提供对象映射、指标口径与角色流程。服装、零售等字段不能写死在公共内核，企业 Profile、凭据和真实数据也不进入本目录。任务持久化是否适合实现为 DSH 插件，须先完成扩展位验证。

每个包必须有：

1. 单一职责与明确的使用者任务；
2. 目标 DSH 版本和依赖的官方扩展接口；
3. 配置、权限、数据来源与失败状态；
4. 源码、可重复构建与必要的行为验证；
5. 启用、停用和回滚说明；
6. 原创或已核许可的素材与合成样例。

包名和发布方式在 M0 兼容性验证后确定；本目录的存在不代表 npm 包已经发布。
