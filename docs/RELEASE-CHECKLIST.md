# 首次公开前检查

这是一份执行清单，不代表检查已经通过。

## 项目与来源

- [ ] 展示名、GitHub 仓库名、项目所有者和 MIT 许可文字经所有者确认。
- [ ] 每个纳入仓库的文件具有清楚来源；第三方代码或素材满足原许可的署名要求。
- [ ] 项目图标、截图和文案不暗示 DeepSeek 官方背书；没有复制业务实例的专有资产。
- [ ] README 的成熟度、插件数量和兼容版本与实际文件及测试一致。

## 文件与数据

- [ ] 按实际待发布文件清单逐项检查：无密钥、Token、Cookie、私钥、`.env`、Profile、会话、客户或财务数据。
- [ ] 检查 Git 历史与待推送对象，而不只检查工作区；发现敏感内容先清理历史再发布。
- [ ] 文档、示例、测试夹具只包含合成数据或获许可的公开材料。
- [ ] 路径与截图不暴露维护者的本机目录、内网地址或业务文件名。

## 插件质量（有插件时）

- [ ] 锁定并注明实际验证过的 DSH 版本；在干净 Profile 完成构建和启动。
- [ ] 新任务、会话继续、草稿、附件、模型与权限未被插件破坏。
- [ ] 失败状态可见；停用插件可恢复原生 UI 且不删除用户数据。
- [ ] 文档给出可复现安装与停用步骤；只声明实测过的能力。

## 发布回读

- [ ] 公开仓库创建后，核对可见性、默认分支、LICENSE 和文件清单。
- [ ] 从公开地址重新读取 README 与首个插件的发布说明。
- [ ] 记录发布日期和与本地待发布内容的提交哈希。
